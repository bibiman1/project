# 呪いの野犬 マシンの候補(D134〜D139)

没の候補もすべて残す(作者 D139「没の一次判断はまかせるが、人間の目でみて採用するケースもあり得るので」)。採用を変えたいときは、名前を言ってもらえば差し替える。

## 三面図の下絵から(`docs/assets/noroi/sanmen/orders/out/`)

| 絵 | 採用 | 没とその理由 |
|---|---|---|
| ぽんぽんカー こちら向き `ponpon_s_*` | 00 | 01〜03 も三面図と合う(00 がいちばん素直) |
| ぽんぽんカー 横 `ponpon_e_*` | 00 | 01 も合う。02〜04 は塗りの擦れが強すぎて地肌が石のよう |
| ぽんぽんカー うしろ `rc_pon_back_00` | — | 顔(目と鼻)が描かれた。前から見た絵になっている |
| ぽんぽんカー うしろ `rc_pon_back2_00` | 00 | |
| ぼぎカー うしろ `rc_bogi_back_*` | 00 を直して使う | 4 つとも、うしろの面に穴が開いている(目穴は横につらぬくので、うしろからは見えない)。00 の穴を、同じ高さの左の木目で埋めた(`rc_bogi_back_00_fixed.png`) |
| ぼぎカー うしろ `rc_bogi_back2_*` | — | うしろの面に四角いこぶが 4 つ足された |
| 車箪笥 西 `tansu_w_*` | — | 隅に余計なかけら(赤とメッキ)。前の面が見えているのに STP がない |
| 車箪笥 東 `tansu_e_*` | — | 黒い漆の色(西とそろわない)。02 は前から見た絵 |
| 車箪笥 東 `tansu_e2_*` | — | 茶色になったが、見えている前の面に STP とナンバーがない |
| 車箪笥 西 `tansu_w3_*` | 00 | 下絵を前の面が見える角度にした。01 は引き出しの金具が T 字、02〜03 も合う |
| 車箪笥 東 `tansu_e3_*` | 00 | 01〜03 も合う |

## 三面図の前の発注(`restyle/`、`rear/`)

| 絵 | 採用 | 没とその理由 |
|---|---|---|
| 赤べこ こちら向き `akabeko_s_*` | 00 | ほかは斜めの角度、黄色や黒の塗り |
| 赤べこ 横 `akabeko_e_*` | 00 | 01 も合う |
| 赤べこ うしろ `aka_rear_*` | 00(胴の上の窓の帯を赤で埋めた) | 02 は赤いテールランプ、03 はパラシュートの包みが足された |
| とりぼぎかー こちら向き `tori_s_*` | 02 | 00、01、03 は親鴨と桶の形が三面図から遠い(一次判断。細かく数えてはいない) |
| とりぼぎかー 横 `tori_e_*` | 00(左右を返して東向き) | 02 は桶が 2 つ。01、03 は形が三面図から遠い(一次判断) |
| とりぼぎかー うしろ `tori_rear_*` | 00 | 01、03 は斜め、02 は子がもの向きがそろう |
| こけし こちら向き `kokeshi_s_*` | 00 | ほかは塗りの色ちがいなど(一次判断) |
| こけし 横 `kokeshi_e_*` | 00 | 01 はこけしが起きている |
| ぽんぽんカー `ponpon_s_*`、`ponpon_e_*` | — | 車輪が外に出た箱形、ジープのような横顔(三面図のドームでない) |
| 車箪笥 `tansu_w_*` | — | 車輪が箱の外の荷車の大きさ(D136 に反する) |
| ぼぎカー うしろ `bogi_rear_*`、`bogi_rear2_*` | — | 斜めから / 縦長の塊(厚み = きーの幅の比でない) |
| ぽんぽんカー うしろ `pon_rear_*`、`pon_rear2_*` | — | ビートルのうしろ姿(テールランプ、ナンバー)/ 車輪が外 |

`tansu_under/` は三面図の前に描いた車箪笥の下絵からの候補(仕上がる前に回数が尽きた分)。`frame/` はスタイルフレームの候補。
