# 制作の材料 2026-09 セッション 1

「ぼぎだぢ制作日記」の材料。霞ヶ浦の断片、アンバリッド・ホテルの手直し、文字と窓の統一、ステータス画面を作ったセッションの作業場所から、消える前に保存したもの。整理はしていない(記事にするときに選ぶ)。

| フォルダ | 中身 |
|---|---|
| `gen/` | PixelLab の生成候補と、生成に渡した下絵。採用しなかった候補も含む(元の PNG のまま) |
| `kb/` `ki/` `final/` `style/` | 霞ヶ浦の下絵、小物、仕上げ、絵柄の見本 |
| `screens/` | ヘッドレスのブラウザで撮った確認用の画面(容量のため WebP に変換、画質 85) |
| `scripts/` | 確認と下絵づくりに使った Playwright と Python のスクリプト |

- ゲームに組み込んだ絵の「前」と「後」は、git の履歴(`field/assets/`)からも取り出せる。ここにあるのは、履歴に残らなかったもの(没の候補、下絵、確認の画面)。
- ファイル名は作業中に付けた略号のままで、時刻順ではない。
