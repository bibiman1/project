### 2. 制作日記を note で公開し、更新を自動化する
- 作者の言葉: 「とても面白い日記になっている。これさ、すごくいいコンテンツになる。なので、noteに公開したい。そして更新も自動化したい。私も読者としてよんでみたい。」(2026-09-27)
- 解釈: 日記を続きもので書き、note に載せる。書くことと載せることを、なるべく人手なしで回す。作者は書き手ではなく、読者として読む。
- 関係するメモ: #1
- 確かめたい点:
  - note には公式の投稿 API がない。非公式の API やブラウザ操作での自動投稿は、規約とアカウント停止の危険がある。note への投稿は作者の手で行うか。
  - 日記を書くきっかけ(週 1 回の定期実行、断片ができるたび、作者の合図)。
  - 公開前に作者が読むか。読むと「読者として読む」楽しみが減り、読まないと事実の誤りが残る危険がある。
  - 自動で更新される読者用のページ(GitHub Pages と RSS)を置くか。
- 状態: 確認中
