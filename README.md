# 惑星総督 試作版

## GitHub Pagesで公開する方法

1. ZIPを展開します。
2. `index.html`、`style.css`、`game.js`、`README.md`をGitHubリポジトリ直下へアップロードします。
3. Commit changesを実行します。
4. Settings → Pages → Deploy from a branchを選びます。
5. Branchをmain、フォルダを/rootにして保存します。

外部ライブラリやサーバーは不要です。ブラウザだけで動作します。
