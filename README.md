ベースは v2.0.0（唯一の正本）。v2.1.0でUI統合＋敵侵攻・人事拡張、本版(v2.1.1)でレスポンシブ対応を追加しました。ゲームロジックは変更していません（CSS中心＋描画追従フックのみ）。外部ライブラリ不使用のフロントエンド完結（index.html / style.css / game.js）。

## 0-4. v2.1.6 調整：アバターの一貫性・表情

## 0. v2.1.1 追加：レスポンシブ対応
--------------------------------------------------
固定3カラム（190px / 1fr / 300px）で狭い画面が破綻していた問題を解消しました。

- レイアウトを CSS Grid のエリア（nav / map / info）で管理し、画面幅で並べ替え。
  - 広幅（>1000px）：従来どおり左ナビ・中央マップ・右詳細の3カラム。
  - 中間幅（≤1000px）：2カラム化。左ナビ＋中央マップを上段、右詳細を下段全幅へ。
  - 狭幅（≤640px）：縦積み（マップ→司令メニュー→詳細）。マップを主役（高さ46vh）にし、ページスクロールを許可。左メニューとヘッダー速度ボタンは横並びラップで縦を圧縮。ボタン等のタップ領域を拡大。
  - 極狭（≤380px）：左メニューを1列化。
  - 低背の横向き端末（高さ≤520px）：マップ高さを抑制。
- 星系マップ（Canvas）は等倍・センタリング描画のままコンテナ寸法に追従。`ResizeObserver`（対応ブラウザのみ、未対応環境はガードで無害化）でコンテナのサイズ変化時に自動再描画。
- ダイアログは従来から `width:min(1000px,96vw) / max-height:88vh` で可変のため、モバイルでもそのまま利用可。
- セーブ構造・ゲームロジックは不変。セーブ互換に影響なし。

## 2. 変更内容
--------------------------------------------------
### 2-1. 統合アクションUI（前版で実装済み・維持）
- 右パネルを常に「① 対象（星系）／② 実行艦隊／③ 行動」の3ブロックへ統一。
- 行動は対象状態で自動切替（未探査→探査へ向かう／自国・無所属→移動／敵国→占領へ向かう）。
- 実行艦隊セレクタを常設し、適任・最寄り・到達可能な艦隊を自動プリセット。
- 星クリック＝常に対象設定。艦隊選択はリスト／マップ上の艦隊記号。実行艦隊はリング表示。
- 押せない場合は理由を画面内表示（司令官/探査船/航続/輸送船）。
- 星側探査の艦隊固定バグ（send(1,…)）を修正済み。

### 2-2. 空艦隊の自動削除（新規）
- 艦隊所属の船が0隻になった艦隊を、全経路で自動削除（`pruneEmptyFleets`）。
- tick・艦隊戦終了・占領戦終了・敵強襲後に実行。
- 削除時、その艦隊に紐づく司令官の任命を解除。削除艦隊が実行艦隊だった場合は選択を解除。
- プレイヤー艦隊の解隊は通知欄に記録。

### 2-3. 戦死者の名簿保持・二階級特進・将官階級（新規）
- 階級章に将官3段（少将・中将・大将）を追加。RANKSは全10段。大将が最上位（頭打ち）。
- 司令官が戦死（艦隊戦敗北・惑星攻略失敗）した際：
  - 戦死フラグ（killed）を立て、二階級特進（戦死時の階級から+2段、大将で頭打ち）を付与。
  - 人事名簿から削除せず記録として残す。名簿では生存者の下に「戦死者」区切りでまとめて表示し、戦死（二階級特進）と明記。
  - 任命候補からは除外。現役定員20名にも数えない（新規着任は生存者数で判定）。

### 2-4. 敵の侵攻（新規）
- 敵対関係（relations<0）で戦艦を含むNPC艦隊は、探知済みのプレイヤー星系を「侵攻航行」目標に選ぶ（確率的）。
- 侵攻艦隊がプレイヤー星系へ到着：
  - 防衛プレイヤー艦隊がいれば従来どおり艦隊戦。
  - 無防備なら強襲判定（NPC攻撃力 対 星系防衛力＋軌道砲台＋人口）。勝てば占領（所属変更・人口減・防衛低下）、負ければ星系防衛が削れNPC艦隊が損傷。
- 占領（母星以外）に成功すると、相手勢力の関係値が敵対側へ低下（報復の下地）。母星占領は従来どおり勢力崩壊＋独立国化。
- 中立/友好（relations>=0）のNPCは自国星系を侵攻しない（仕様§4-9維持）。

## 3. 操作方法（要点）
--------------------------------------------------
- 星をクリック→右①に対象、②に適任の実行艦隊、③に行動ボタン。押せない時は理由が③に出ます。
- 実行艦隊は②セレクタ／左リスト／マップの艦隊記号で切替。
- 占領：敵星へ「占領へ向かう」。到着済みなら「占領する（この星系）」。探査船のみでも可（成功率低）。
- 資源輸送：輸送船を含む実行艦隊で「資源輸送」。施設建築：自国星で「この星系に施設を建築」。修理：自国ドック星で待機中に「修理」。
- 人事名簿：生存者の下に戦死者（二階級特進・任命不可）を記録表示。
- OK（星系マップへ）：選択解除。

## 6. 既知の問題・制限事項
--------------------------------------------------
- ブラウザ実機（Canvas描画・pointer操作・ダイアログ表示）の目視確認は本環境では未実施。GitHub Pages 公開後の確認を推奨。

- v2.0.0からの設計上の弱点（各勢力の母星が外れ星系に配置されると母星制圧ルートが約21.6%で封鎖され得る／勝利は同盟ルートで可能）は本版でも未対応。
- 「移動」と「探査」は到着処理が実質同一のため、対象状態で自動切替する設計に統一しています。
