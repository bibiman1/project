# 惑星総督 v1.5.3 統合全文版

## 追加仕様
- 艦隊戦は、到着星系に敵艦隊が実在する場合のみ開始
- 敵艦隊がいない場合は、そのまま星系到着または惑星防衛戦へ進む
- NPC3勢力に探査船・戦艦・輸送船の混成艦隊を配置
- NPC艦隊は15ターンごとに未調査星系を探査し、無所属星系を編入
- 調査先がない場合は自勢力周辺を哨戒
- プレイヤーが探査済みの星系にいるNPC艦隊のみマップ表示
- 敵対状態で同じ星系に入ると艦隊戦
- 艦隊戦はラウンド制、次ラウンド・自動進行・撤退に対応
- 艦隊戦勝利後、敵惑星なら占領選択へ進む

HTML、CSS、JavaScriptの全文置換版です。
