# 惑星総督 v1.3.2 艦隊戦・占領版

- NPC3勢力に初期防衛艦隊を配置
- 探査済み星系ではNPC艦隊を勢力色で表示
- 敵駐留艦隊とのラウンド制艦隊戦
- 標準戦闘、全力攻撃、防御重視、撤退
- 命中、回避、防御、損傷、撃沈
- 次ラウンド、自動進行、撤退操作
- 戦闘結果をOKダイアログで表示
- 占領命令を追加。戦艦＋輸送船が必要
- 駐留艦隊、軌道砲台、惑星防衛網、降下判定の段階戦
- 占領成功時に人口減少、治安30、防衛力10
- 艦隊戦・占領成功で司令官経験値を獲得
- 既存の航続距離、造船ドック、人事階級、未踏星系、外れ星系を維持

## v1.3.2 UI修正
- 艦隊詳細・艦隊命令画面に「OK（基本画面に戻る）」を追加
- OK押下で目的地選択と航続距離円を解除
- 艦隊現在地の星系詳細へ戻し、星系マップを基本画面として維持
- 画面下部へ操作終了通知を表示

## v1.3.2 航続距離円修正
- 航続距離円の中心を出発惑星ではなく宇宙船の現在位置へ変更
- 航行中も毎ターン宇宙船の移動位置に追従
- 燃料消費に応じて円の半径を毎ターン縮小
- 目的地までの線も宇宙船の現在位置から描画
- 移動中に目的地を比較する距離計算も現在位置基準へ変更
