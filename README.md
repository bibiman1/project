# FP9 ライフラインチャート GitHub Pages版

## 公開方法
1. ZIPを展開します。
2. `index.html`、`style.css`、`script.js`をGitHubリポジトリ直下へアップロードします。
3. `Commit changes`を押します。
4. GitHub Pagesの公開処理完了後、公開URLを再読み込みします。

## ファイル
- `index.html`: 画面
- `style.css`: 見た目
- `script.js`: 入力、編集、チャート、画像保存、コピー

## 注意
入力内容はサーバーへ送信しません。GitHub Pagesで動く静的サイトです。
