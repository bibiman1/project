# 惑星総督 v2.0.0 統合回復版

退行を精査し、主要仕様を再統合した全文版です。

## 回復・修正
- ダイアログ終了後に直前の時間速度へ復帰
- 速度ボタンの選択表示を同期
- 敵艦隊戦前に探査情報を確定
- 司令官未任命艦隊の出航を禁止
- 未探査星系の所属・人口・資源を秘匿
- セーブデータのバージョン管理と旧データ補完
- 探査・艦隊戦・占領の経験値と昇進
- 戦闘敗北・攻略失敗時の死亡除隊
- 母星、勢力崩壊、独立国化、勝利条件
- 外交支援・同盟・敵対
- 自国ドックでの艦隊修理
- 輸送船による星系間資材・燃料輸送
- 施設建築の自国星系切替タブ
- 複数造船ドック切替
- 探査基地レベルに応じた敵艦隊探知
- 自国星系では不要な占領表示を非表示
- 自国宇宙船だけを一覧表示

## 維持
航続距離円、星系別資源、ガス惑星の燃料プラント・軌道施設、建築・造船時間、NPC探索、艦隊戦、惑星防衛戦、探査船単独占領、司令官任命を維持しています。
