v2.0.0（統合回復版）を正本とし、UI層のみを改修しました。ゲームロジック（戦闘・占領・NPC・資源・セーブ等）は変更していません。外部ライブラリ不使用のフロントエンド完結（index.html / style.css / game.js）。

## 2. 変更内容（v2.0.0 → v2.1.0：UIのみ）
--------------------------------------------------
操作文法の統一（艦隊起点／星起点の2系統混在を解消）
- 右パネルを常に同じ3ブロックへ統一：**① 対象（星系）／② 実行艦隊／③ 行動**。
- 入口（星クリック／艦隊クリック）が違っても、着地する操作面は同一。
- ③ 行動は対象の状態で自動切替：
  - 未探査 →「探査へ向かう」
  - 探査済み・自国／無所属 →「移動」
  - 探査済み・敵国／独立国 →「占領へ向かう」
- 命令プルダウン（移動/探査）を廃止し、文脈ボタンへ統一。

実行艦隊セレクタの導入
- ② に自国艦隊のセレクタを常設。対象に対して**適任・最寄り・到達可能**な艦隊を自動プリセット（探査時は探査船を含む艦隊を優先）。

マップ操作の一貫化（隠れモード解消）
- 星クリック＝常に「対象に設定」。
- 艦隊の選択は左の艦隊リスト、またはマップ上の艦隊記号クリックに限定。
- 実行艦隊はマップ上でリング表示。航続距離円は実行艦隊基準で描画。

不可理由の画面内表示
- 「司令官が必要」「探査船が必要」「航続距離外」「輸送には輸送船が必要」等を③の面に表示し、該当ボタンは非活性化。

管理操作の集約
- ③の下に「司令官を任命・交代／修理／OK（星系マップへ）」を常設。自国星の「施設を建築」、到着済み敵星の「占領する（この星系）」も同面に統合。
- OK＝選択解除（航続距離円を消して星系マップへ戻る）。

不具合修正（実バグ相当）
- 星側探査が常に第1艦隊固定（`send(1,…)`）だった問題を修正。実行艦隊セレクタの選択艦隊で探査するよう変更（複数探査艦隊でも正しく動作）。

--------------------------------------------------
## 3. 操作方法
--------------------------------------------------
- 基本画面は星系マップ。星の丸印をクリックすると右パネル①に対象、②に適任の実行艦隊が自動選定され、③に行動ボタンが出ます。
- 実行艦隊を変えたい場合は②のセレクタ、または左の艦隊リスト／マップ上の艦隊記号をクリック。
- ③の行動ボタン（探査へ向かう／移動／占領へ向かう）を押すと命令。押せない場合は理由が③に表示されます。
- 占領：敵星へ「占領へ向かう」。到着時に敵艦隊がいれば艦隊戦、その後に占領選択。到着済みなら「占領する（この星系）」。探査船のみでも可能（成功率低）。
- 資源輸送：輸送船を含む実行艦隊で「資源輸送」→輸送先（自国）と数量を指定。
- 施設建築：自国星を対象にして「この星系に施設を建築」。
- 修理：実行艦隊が自国ドック星で待機中に「修理」。
- OK（星系マップへ）：選択解除して基本画面へ。
