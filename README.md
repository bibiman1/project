# 惑星総督 v1.4.0 人事・母星・建造拡張版

- 初期人事に候補生、尉官、佐官が在籍
- 候補生は能力低め、上位階級ほど能力範囲が高い
- 毎年1〜3名の候補生が着任、現役定員20名
- 艦隊戦・占領戦敗北時に司令官が死亡除隊
- 艦隊選択時に航続距離円を表示
- 艦隊選択中はマップの星クリックで目的地を選択
- 艦隊命令画面に常時OKボタン
- 敵母星を占領すると勢力崩壊
- 残存領土・艦隊は独立国化し、積極拡張しない
- 独立国は勝利条件の対象外
- 造船は即時完成せず、探査船18T・輸送船28T・戦艦45T
- 完成船はドックプールへ収容
- ドックLv×4隻の収容・建造枠、増築可能
- 宇宙船ステータスを別ダイアログで表示
- 船ごとにLv・耐久・攻撃・防御・燃料・将来増強枠を表示
