# 惑星総督 運用・物流実装版

## 追加機能
- localStorageによる10ターンごとの自動セーブ
- 手動セーブ、読込、セーブ削除
- 艦隊新設、名称変更、空艦隊解散
- 同一惑星の待機艦隊間で艦艇を移籍
- 1艦隊10隻上限
- 輸送船1隻につき貨物容量300
- 資材・燃料の積載と到着時の自動荷下ろし
- 母港への帰還命令
- 自国惑星到着時の燃料補給
- 造船ドックでの自動修理
- 既存の施設建築、情報秘匿、人事、司令官、艦隊戦、惑星攻略戦を継続

ZIPを展開し、4ファイルをGitHubリポジトリ直下へアップロードしてください。

## 修正内容
- 初回接触後の選択ボタンが閉じず、画面が進まない不具合を修正
- 選択後に関係値、通知、セーブ、画面表示を即時更新
- 艦隊司令官が未任命の場合は出航不可
- 初期探査艦隊には操艦能力が最も高い部下を自動任命

## 航続距離可視化
- 艦隊選択時、星図上に現在の航続圏を円で表示
- 目的惑星までの直線距離を表示
- 到達可能は緑線、航続力不足は赤線
- 目的地一覧に距離、到着ターン、到達可否を表示
- 艦隊詳細に航続力、必要燃料、到着ターンを表示
- 星図上の惑星をクリックして航路をプレビュー

## v0.8.2 接触ボタン再修正
- 接触選択を汎用ダイアログ処理から分離
- 各ボタンへaddEventListenerで直接クリック処理を登録
- preventDefaultとstopPropagationを追加
- 選択後に関係値を通知欄へ明示
- 画面左上にv0.8.2を表示し、GitHub Pagesの更新確認を可能にした
