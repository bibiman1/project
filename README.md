# 惑星総督 v2.01（統合・仕様整合版）

外部ライブラリ不使用のフロントエンド完結（index.html / style.css / game.js）。
GitHub Pages 等の静的ホスティングで動作します。

--------------------------------------------------
## 0. 重要な前提（正本と仕様の不一致について）
--------------------------------------------------
- 受領ZIPのファイル名は「planet-governor-v200-integrated」でしたが、**中身の実装は v1.3.2**（index.html の title、README、localStorage キー `planetGovernorV100` すべて v1.3.2）でした。
- そのため、仕様書 §4 に列挙された「現在の主要仕様」のうち、以下は**受領コードには存在していませんでした**（＝仕様と実装の不一致）。勝手に「実装済み」とはせず、本版で新規実装しています。
  - 施設建築（§4-5）：関数・UIとも未存在
  - 造船の建造時間・キュー（§4-6）：`build()` が即時 dockPool 追加＝即時完成（禁止事項違反）
  - 資源輸送の実行（§4-12）：`輸送`命令は移動のみで資源移動なし
  - NPC探索AI（§4-8）：NPCは静的な防衛艦隊のみ
  - 母星崩壊・勝利判定（§4-11）：未存在
  - 艦隊修理（§4-6）：未存在
  - 探査基地の探知範囲（§4-8）：未存在
  - 人事の年次着任・死亡除隊（§4-7/4-9/4-10）：未存在
- 併せて、仕様と矛盾していた点：
  - 占領要件（§4-10「探査船1隻でも占領可能」）に対し、受領コードは戦艦＋輸送船を必須化して探査船占領を禁止していた → 仕様準拠へ修正。
  - 到着処理で `order` を到着前に「待機」へ上書きしており、`占領`／`輸送`の到着処理が発火しない潜在バグ → 修正。
  - マップ描画が X=幅、Y=高さの別倍率で、航続距離円（等倍）と惑星位置がずれる（§4-1/4-2違反）→ 等倍・センタリングへ修正。

## 2. 変更内容（v1.3.2 → v2.01）
--------------------------------------------------
新規実装
- 施設建築（§4-5）：地上/軌道の8種、最大Lv5、1星系同時1件、資金＋対象星系資材＋建築ターンを消費。ガス惑星は鉱石プラント・居住区・防衛基地を建築不可。自国星系をタブ切替。建築可否と不可理由を画面内表示。効果を各所へ反映（生産強化・人口上限・防衛・造船枠・探知・備蓄上限・軌道防衛）。
- 造船の建造時間・キュー（§4-6）：探査船18／輸送船28／戦艦45ターン。即時完成しない。完成後はドックプールへ収容（自動編入なし）。ドックLvで造船枠増加。
- 艦隊修理（§4-6）：ドックのある自国星系で待機中の自軍艦を修理。対象星系の資材を消費。資材不足時は理由をダイアログ表示。
- 資源輸送（§4-12）：輸送船を含む自国艦隊で自国星系間を輸送。積載上限（輸送船×200）、積込元備蓄減・輸送先備蓄増・上限超過分は届かない旨を表示。
- NPC探索AI（§4-8）：NPC3勢力が航続・燃料の範囲で無所属・利用可能星系を探索し編入。対象がなければ哨戒。プレイヤーへ星系情報は開示しない。
- 探知範囲（§4-8）：自国星系ごとに基礎26＋探査基地Lv×24。探知できるNPC艦隊のみマップ表示。
- 人事の年次着任（§4-7）：毎年1〜3名の候補生（能力低め）が着任。現役定員20。
- 死亡除隊（§4-7/4-9/4-10）：艦隊戦敗北・惑星攻略失敗で司令官を戦死・除隊し、名簿と任命候補から除外。撤退時は死亡しない。
- 母星・勝利・崩壊（§4-11）：各主要勢力に母星を1つ設定。母星占領で勢力崩壊→残存星系・艦隊は独立国化。主要3勢力を母星制圧または同盟で勝利（独立国残存は不問）。勝利画面でゲーム停止。
- 外交操作（§4-11）：接触済み勢力に「支援（資金500・関係+15）／同盟提携（関係60以上）／敵対宣言」。

修正・整合
- 占領要件を仕様準拠に変更（探査船のみでも占領開始可能。輸送船不在時は占領力低下の警告を戦闘ログに表示。占領力は輸送船兵員＋全艦の基礎値＋司令官武力で算定）。
- 到着時の `order` 上書きバグを修正（占領・輸送の到着処理が正しく発火）。
- マップ縮尺を X/Y 等倍＋センタリングに統一（航続距離円と惑星位置の不一致を解消）。クリック判定も同一変換に統一。
- サイドバー艦隊一覧を自国艦隊のみに限定（NPC艦隊の誤操作を防止）。
- セーブキーを更新し、旧セーブの自動移行を追加（無条件読込を避け、フィールド補完してから読込）。
- タイトル・表示バージョンを v2.01 に更新。

## 4. 操作方法
--------------------------------------------------
- 基本画面は星系マップ。惑星の丸印クリックで惑星選択、左の「艦隊」から艦隊選択で右側に艦隊詳細・命令。
- 艦隊命令：命令種別と目的地を選び「命令を実行」。目的地選択で航続距離円と距離/航続力/到着ターンを表示。航続外は実行不可。
- 「OK（基本画面に戻る）」で目的地選択・航続距離円を解除し星系マップへ復帰。ダイアログ終了で開く前の速度へ復帰（戦闘・勝利中は意図的に停止）。
- 探査：未探査星系を選び「(艦隊)で探査」または艦隊命令の「探査」。
- 施設建築：左「施設建築」→星系タブを選び各施設の「建築/増設」。不可時は理由を表示。
- 造船ドック：左「造船ドック」→建造（時間経過で完成）→プールから待機艦隊へ補充。損傷艦は「全艦修理」。
- 占領：敵星系へ艦隊命令「占領」。敵艦隊がいれば先に艦隊戦、いなければ惑星防衛戦。探査船のみでも可能（成功率は低い）。
- 輸送：輸送船を含む自国艦隊で命令「輸送」→輸送先（自国）指定→資材/燃料を積んで出航。
- 外交：右下「外交」の勢力カードをクリックで支援/同盟/敵対。

## 5. セーブデータ互換性
--------------------------------------------------
- 本版のセーブキーは `planetGovernorV201`。手動/自動セーブともこのキー。
- 旧 v1.3.2（`planetGovernorV100`）のセーブが存在し新キーが無い場合、読込時に旧データを読み、`fac`（施設）、`buildQueue`／`shipQueue`、`homeworld`、`allied`／`collapsed`／`won`／`nextPerson` 等の不足フィールドを補完してから適用します（無条件読込はしません）。
- 旧セーブには母星フラグが無いため、旧データ継続時は母星占領による勝利が発生しない可能性があります（新規開始を推奨）。

## 7. 既知の問題・制限事項
--------------------------------------------------
- ブラウザ実機（Canvas描画・pointer操作・ダイアログ表示）の目視確認は未実施。本環境はヘッドレスのためロジック検証に留まります。GitHub Pages 公開後の実機確認を推奨します。
- 命令種別のうち「惑星防衛」「迎撃」は移動として解決され、独立した専用処理は持ちません（v1.3.2 の挙動を踏襲。艦隊戦は同一星系に敵対艦隊が実在する場合に発生）。
- NPCのAIは「無所属・利用可能星系の編入」と「哨戒」中心の簡易版で、対プレイヤー侵攻や施設建築は行いません。
- NPCの知識は簡易表現（未探査情報はプレイヤーへ非開示だが、勢力別の探査済みマップは厳密には保持していません）。
- 旧セーブ継続時は母星未設定のため勝利条件（母星制圧）が成立しない場合があります。
