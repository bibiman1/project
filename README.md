# 惑星総督 v0.9.2 艦隊司令・燃料運用UI版

## 主な変更
- 艦隊選択時に専用の艦隊命令パネルを表示
- 移動、探査、防衛、占領、輸送、帰還命令
- 燃料を出航時一括ではなく航行中に毎ターン消費
- 燃料切れ時は漂流
- 自国または同盟惑星だけで補給
- 艦隊一覧と各船の燃料ゲージ
- 航続圏、距離、到着ターン表示
- 通知を画面下部へ固定し、履歴ダイアログを追加
- セーブ関連を「セーブ管理」ダイアログへ集約
- 「新しい星域」を左下へ移動し、確認ダイアログを追加
- 接触ボタン修正を継続

ZIPを展開し、index.html、style.css、game.js、README.mdをGitHubリポジトリ直下へアップロードしてください。

## v0.9.2 起動修正
- 存在しない旧ボタン参照を削除
- 通知履歴初期化後にゲームを開始するよう順序修正

## v0.9.2 操作修正
- 艦隊カードのクリック処理をインライン処理から直接イベント登録へ変更

- 命令実行時の入力要素と状態を検証
- 航行中、占領対象不正などの理由を通知表示
