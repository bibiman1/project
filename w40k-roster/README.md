# W40K ロスター＆戦闘記録

Warhammer 40,000 **第11版・アデプトゥス・メカニカス専用**のロスター管理・対戦進行トラッカー・ルール備忘メモをブラウザだけで完結させるツールです。ビルド不要、素のHTML/CSS/JSで動作します。他陣営・他版への対応は想定していません（詳細は `docs/rules-notes.md` を参照）。

## 機能

- **ロスター管理**: ロスター（ファクション・ポイント上限）とユニット（モデル数・ポイント・キーワード・備考）を作成・編集・複製・削除。ポイント上限超過時は表示で警告。JSONでのエクスポート/インポートに対応。
- **対戦トラッカー**: ロスターを選んで対戦を開始し、バトルラウンド・CP（コマンドポイント）・VP（勝利ポイント）・ユニットの撃破/状態メモ・ラウンドログを記録。
- **ルール早見・備忘メモ**: フェイズごとにカテゴリ分けした自分用メモを登録し、タイトル・タグ・本文で検索。

## データの保存

すべてのデータはブラウザの `localStorage` に保存されます。サーバーへの送信は一切行いません。別端末や別ブラウザに移す場合は、ロスター詳細の「📤 エクスポート」でJSONを書き出し、「📥 インポート」で読み込んでください。

## 使い方

`index.html` をブラウザで開くだけで動作します。GitHub Pages で公開する場合はこのディレクトリをそのまま配信してください。
