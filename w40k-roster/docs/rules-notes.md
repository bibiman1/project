## 1. コアルール（11版・全88ページ読了）

このコアルールは**ゲームプレイの手順・判定方法のみ**を扱う資料。ポイントコストや編成制限（同一ユニットの上限数、複数体目のポイント増加＝いわゆる「ポイントステッパー」等）は**一切記載がない**。それらは別のポイント資料（ムニトルム・フィールド・マニュアル相当、未入手）で管理されている可能性が高い。

「ポイントステッパー」（同一ユニット2体目・3体目以降のポイント増加）はWeb検索で実在が確認できた11版の仕組みだが、増加額はユニットごとに個別設定でありムニトルム・フィールド・マニュアル本体は未入手のため、アプリ側で自動計算する仕組みは作らない方針とした（2026年時点でユーザーと合意済み）。ロスターの「合計ポイント」欄に、資料を見ながら正しい値をそのまま入力する運用で対応する。

### バトルの基本構造
- バトルラウンドは7ステップ: ターン開始時 → **指揮フェイズ** → **移動フェイズ** → **射撃フェイズ** → **突撃フェイズ** → **白兵フェイズ** → ターン終了時（5フェイズの正式名称はこの5つ。アプリのフェイズチェックリスト・ルールメモのカテゴリ名として採用済み）。
- 「戦闘ショック」は独立フェイズではなく指揮フェイズ内のステップ。ユニットが戦闘ショック状態or半壊状態なら毎ターン戦闘ショックロールが必要。戦闘ショック中は【確保】が「-」になり、策略の対象にできず、アクションを開始・完了できない。
- CP（コマンドポイント）は指揮フェイズ開始時に両プレイヤーが1点ずつ自動獲得する（「コアCP」）。

### データシートとユニット構成
- データシートの構成: プロフィール（移動/耐久/防御/傷/統率/確保、任意でスペシャルセーヴ値＝特防）、射撃武器・白兵武器（射程/攻撃回数/射撃or近接技能/攻撃力/貫通値/ダメージ量）、アビリティ、キーワード（属性キーワード／陣営キーワード）、ユニット構成・ウォーギアオプション。→ アプリのユニット入力フォームの元ネタ。
- 隊形（Coherency）: 同一ユニット内の兵は水平2mv以内・垂直5mv以内で隣接し、全体が水平9mv以内に収まる必要がある。移動終了時にこの隊形を維持できないと兵は戦場から取り除かれる（撃破扱いだが撃破時の誘発ルールは発生しない）。

### 移動フェイズ
- 移動タイプ: 静止／通常移動／全力移動（D6ロール＋移動力）／退却移動（接敵中のみ、戦術的後退か決死の脱出を選択）／降車移動／突入移動。
- 兵の移動は「まっすぐ移動」と「回転」の組み合わせ。回転は距離消費なし。

### 射撃フェイズ
- 射撃タイプ: 通常射撃／アサルト射撃（【アサルト】武器＋全力移動後でも可）／至近射撃（【至近】武器または モンスター/ビークルが接敵中の敵に）／間接射撃（【間接】武器で視認不可の対象に、ヒットロールにペナルティ）。

### 攻撃の解決手順（射撃・白兵共通）
1. 武器の選択 → 2. 攻撃対象の選択 → 3. 攻撃の解決（攻撃ダイスを集める）→ 4. 攻撃手順（ヒットロール→ウーンズロール→セーブロール→ダメージの処理）。
- 同種攻撃（射/接/攻/貫/ダが同一）はまとめて処理。
- セーブロールは対象ユニット内でグループ化（キャラクターは基本別グループ、傷を失っているキャラクター以外は優先度が下がる等のルールあり）。

### 突撃・白兵フェイズ
- 突撃: 2D6の突撃ロール距離内で、選択した敵ユニット全てに接敵する必要がある。
- 白兵フェイズは「先手」ユニットから交互に解決していく複雑な手順（接敵移動→白兵→再編移動）。「先手」は突撃した自軍ユニットが得る。

### 上級ルール
- **モンスター/ビークル**: 移動時に味方・敵ユニットを通り抜け可能。接敵中の敵への射撃はヒットロールに-1（至近射撃は除く）。
- **兵員輸送**: 輸送枠・乗車・降車（高速降車/戦術的降車/戦闘降車）・緊急降車移動のルール。
- **合流ユニット**: 指揮官/支援アビリティを持つユニットが護衛ユニットを率いて単一ユニットとして扱われる仕組み。合流ユニットは全構成ユニットのキーワードを持ち、指揮官/支援兵が付与するアビリティは自身が撃破されるまで有効。攻撃時に用いる【耐】は護衛兵の中の最高値。→ アプリの「合流グループ」機能の元ネタ。
- **戦略的予備戦力**: 初期配置せず後続投入するユニット（合計ポイントの50%上限）。第2バトルラウンド以降に突入移動で戦場に到着。第3ラウンド終了時までに到着しないと撃破される。
- **飛行と進撃**: 飛行キーワード持ちは「宙に舞い上がる」宣言で最大距離-2mvの代わりに障害物や他兵を無視して移動可能。進撃移動は最も近い敵ユニットに接敵するよう強制される移動。
- **航空機**: 戦略的予備戦力配置必須、突入移動のみ、白兵戦は飛行ユニットとのみ可能。

### コアアビリティ一覧（レファレンス、抜粋）
支援、痛みを知らぬ者、先手、射撃デッキ、ヘヴィ、ホバー、遮蔽無効、間接射撃、浸透戦術、ランス、指揮官、会心ヒット、単独工作員、メルタ、一発限り、ピストル、精密攻撃、サイキック、ラピッドファイア、斥候、隠密能力、支援、超重歩兵器、連続命中、噴射、ツインリンク、特効、蹂躙、暴発、恐るべき最期、会心ウーンズ、縦深攻撃、追加攻撃、ブラスト、アサルト、至近 など。→ アプリの武器アビリティ欄はこれらのキーワードを自由記述で入力する想定（キーワードごとの自動判定はしない）。

### ルール補遺・FAQ
- 初期兵数と半壊状態の判定表、撃破処理の順序、異なる移動力の兵が混在する場合の扱い、白兵戦を宣言できるが実行できない場合のパス処理、蘇生ルール、地形エリア外の作戦目標の扱いなど、細かい裁定が多数。アプリの挙動には影響しないため個別の転記は省略。

## 2. アデプトゥス・メカニカス 陣営パック Ver1.1

- デタッチメントは「デタッチメントルール」＋「ストラタジム（複数、各1CPが多い）」＋「強化（10〜35PT程度）」の3点セットで構成される。→ アプリのロスターの「デタッチメント編集」「ストラタジム追加」「ユニットの強化」の構造と一致。
- 陣営パックには新規/更新データシート、ポイント・アビリティ変更、FAQも含まれる。こうした差分情報はアプリには反映しない（アプリはルール正誤判定をしないツールのため）。ロスターに入れるユニットの数値はユーザーが都度資料を見ながら入力する運用。

## 3. ユニバーサル・ルール・アップデート Ver1.1

全陣営共通のコアルール運用の明確化。アプリはゲームルールの正当性を判定しない（あくまでロスター/進行の備忘ツール）ため、これらはコードには反映していない。参考として要点のみ記録:

- 「味方ユニットに策略を0CPで使える」という効果で策略名が指定されていない場合は、実質「その策略のCPコストを1CP減らす」効果として扱う。
- 同一フェイズ/ターン中にすでに他ユニットへ発動済みの策略を再度使えるようにする効果は、対象の策略名が明記されている場合のみ有効。
- 「攻撃側が自軍ユニットの12mv以内にいる場合のみ攻撃対象にできる／12mv以内にいない場合は対象にできない」という趣旨の策略のうち、後者（対象にできない、というタイプ）は距離が18mvに変更される。
- 「全滅した自軍ユニットと同一のユニットを新たに自軍に追加する」策略には「このバトル中1回まで」という制限が付与される。
- 兵員輸送ユニットから降車したユニットの移動タイプの扱いに関する明確化（降車後に突撃可能な移動タイプの区別）。
