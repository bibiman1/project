# ルール資料 開発メモ

このアプリを開発する中でユーザーからアップロードされた公式PDF資料の要点を、開発の参考用にまとめたもの。

**注意**: 元PDFはGames Workshop発行の著作権保護されたコンテンツのため、このリポジトリにはファイル自体も本文の転記も含めない。ここに書くのは、アプリの用語・構造を検討する上で必要な事実関係を自分の言葉で要約したものに限る。原文を参照したい場合は都度ユーザーにPDFを再アップロードしてもらう。

## 参照した資料

1. 『ウォーハンマー40,000 コアルール』日本語版 Ver.（2026年時点の最新配布版）
2. 『アデプトゥス・メカニカス 陣営パック Ver 1.1』（2026年7月22日適用）
3. 『ユニバーサル・ルール・アップデート Ver 1.1』（2026年8月26日適用）

## 1. コアルール

- バトルラウンドは7ステップ: ターン開始時 → **指揮フェイズ** → **移動フェイズ** → **射撃フェイズ** → **突撃フェイズ** → **白兵フェイズ** → ターン終了時。5フェイズの正式名称はこの5つ（→ アプリのフェイズチェックリスト・ルールメモのカテゴリ名として採用済み）。
- 「戦闘ショック」は独立フェイズではなく、指揮フェイズ内のステップ（コアCP獲得の次）。ユニットが戦闘ショック状態 or 半壊状態なら毎ターン戦闘ショックロールが必要。
- CP（コマンドポイント）は指揮フェイズ開始時に両プレイヤーが1点ずつ自動獲得する（「コアCP」と呼ぶ）。策略はこのCPを消費して発動する。
- データシートの構成: プロフィール（移動/耐久/防御/傷/統率/確保）、射撃武器・白兵武器（射程/攻撃回数/射撃or近接技能/攻撃力/貫通値/ダメージ量）、アビリティ、キーワード（属性キーワード／陣営キーワード）。→ アプリのユニット入力フォーム（プロフィール6項目・武器一括入力・アビリティ一括入力）の元ネタ。

## 2. アデプトゥス・メカニカス 陣営パック Ver1.1

- デタッチメントは「デタッチメントルール」＋「ストラタジム（複数、各1CPが多い）」＋「強化（エンハンスメント、10〜35PT程度）」の3点セットで構成される。→ アプリのロスターの「デタッチメント編集」「ストラタジム追加」「ユニットのエンハンスメント」の構造と一致。
- 陣営パックには新規/更新データシート、ポイント・アビリティ変更、FAQも含まれる。こうした差分情報はアプリには反映しない（アプリはルール正誤判定をしないツールのため）。ロスターに入れるユニットの数値はユーザーが都度資料を見ながら入力する運用。

## 3. ユニバーサル・ルール・アップデート Ver1.1

全陣営共通のコアルール運用の明確化。アプリはゲームルールの正当性を判定しない（あくまでロスター/進行の備忘ツール）ため、これらはコードには反映していない。参考として要点のみ記録:

- 「味方ユニットに策略を0CPで使える」という効果で策略名が指定されていない場合は、実質「その策略のCPコストを1CP減らす」効果として扱う。
- 同一フェイズ/ターン中にすでに他ユニットへ発動済みの策略を再度使えるようにする効果は、対象の策略名が明記されている場合のみ有効。
- 「攻撃側が自軍ユニットの12mv以内にいる場合のみ攻撃対象にできる／12mv以内にいない場合は対象にできない」という趣旨の策略のうち、後者（対象にできない、というタイプ）は距離が18mvに変更される。
- 「全滅した自軍ユニットと同一のユニットを新たに自軍に追加する」策略には「このバトル中1回まで」という制限が付与される。
- 兵員輸送ユニットから降車したユニットの移動タイプの扱いに関する明確化（降車後に突撃可能な移動タイプの区別）。

## 今後の方針

- 新しい資料が来たら、この形式でセクションを追記していく（資料名・適用日・要点・アプリへの影響）。
- アプリの挙動に直接影響する変更（用語変更など）がある場合は、対応するコード変更のコミットメッセージでこのファイルの該当箇所も一緒に更新する。
